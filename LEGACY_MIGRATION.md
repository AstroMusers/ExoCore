# Legacy migration notes

This repository is the canonical ExoCore curriculum. The older directory tree served as an earlier working version and included a different module taxonomy. The content was valuable, but the naming was inconsistent and the folder structure gradually expanded into a clearer teaching architecture.

## Canonical consolidation

The following older labels map into the modern organization used in this repository:

* `Databases` → `Catalogs`
* `Software` → `Data_Analysis_and_Modeling_Software`
* `Utility Software` → `Utility_Software`
* `Exoplanet Community` → `Exoplanet_Resources_and_Collaborations`
* `Citizen_Science` → `Citizen_Science`
* `Data_Repositories` → `Data_Repositories`
* `Data_Structures` → `Data_Structures`

## What was preserved

The historical version contributed useful continuity, especially in naming and teaching progression. The valuable pieces retained in the active repository include:

* the legacy lesson intent around catalogs, data access, community resources, and software workflows;
* the historical notebook progression for the same core exoplanet topics;
* the broader framing of ExoCore as a modular open-science curriculum;
* the earlier educational emphasis on hands-on notebook-based training.

## Why the new structure is better

The active version improves clarity by using explicit, standardized names that map naturally onto the lesson content and repository layout. This makes the curriculum easier to browse, easier to maintain, and easier to teach to students who are new to exoplanet research.

## Archive status

The older folder is retained only as a historical reference. The modern ExoCore layout is the authoritative version for teaching, maintenance, and future updates.
